# Dinesh Flight Simulator

The Dinesh Flight Simulator is a flight simulation and education tool designed to help educate and train students about flight. It was written as the team's summative project for the ICS4U course.

## Features

The *Dinesh Flight Simulator* has several features that enhance the flightness and simulatorness of the flight simulator.

The features are divided into two major sections; the free flight section and the diagram section.

For the free flight section, features include:

- The ability to fly aircraft  
- The ability to spawn aircraft  
- The ability to manage aircraft  
- The option to select from 7 different aircraft and ground craft  
- A heads up display for information of the selected aircraft  
- Custom terrain with full collisions  
- Custom spawn locations  
- Mouse and camera locking

For the diagram section, features include:

- A cockpit viewer  
- An airplane viewer  
- An aviation jobs viewer  
- Free cam  
- Display board

Other features include:

- Main menu  
- Pause menu  
- Camera settings menu

## Development

The *Dinesh Flight Simulator* was built in the independent development engine Godot, using the languages of GDScript and GDShader.

One external package was used to facilitate the creation of the free-flight physics engine, being the Godot Asset *Godot Aerodynamic Physics*, built by user *addmix*. This package handled the complex physics calculations required for flight and also included models for the following planes: *Cessna172*, *F14, Blackhawk*, *Su57*, *Catalina*.

There were several 3D models used to facilitate the aircraft anatomy and cockpit viewer. Most of them were pulled from *cgtrader*, including the airplane, the hangar, a large whiteboard screen, the chairs, and the entire airport scene. One model was pulled from *SketchFab*, which was used to model the airplane cockpit. 

Additional 3D models and textures were created using the 3D design software Blender. These include the terrain, the water texture, the Airdrop/Car vehicle, and the Transport vehicle.

## Downloading the Code 

In order to download the *Dinesh Flight Simulator*, users must simply download an appropriate release from [https://github.com/malcolmjsingh/flight-simulator/releases](https://github.com/malcolmjsingh/flight-simulator/releases) and run the executable file in the downloaded zip folder.
